# 🚀 Professional Portfolio | Ishan Rawat

A modern, responsive personal portfolio website built to showcase web development skills and projects. This site features a sleek UI, custom CSS animations, and a project gallery.



---

## 👤 About Me
I am **Ishan Rawat**, a Computer Science and Engineering student at **K.R Mangalam University**. I am currently focusing on mastering the **MERN stack** and building innovative web applications. This portfolio represents my journey, skills, and the consistent effort I put into my professional growth.

## ✨ Features
* **Responsive Layout:** Fully optimized for mobile, tablet, and desktop screens using CSS Flexbox and Grid.
* **Dynamic Hero Section:** A striking introduction with a color-shifting animation on the title.
* **CSS Cross-fade Carousel:** An automated image slider in the Projects section built entirely with CSS keyframes.
* **Interactive UI:** Includes hover states for skill cards, smooth scrolling for navigation, and a "Back to Top" functionality.
* **Clean Codebase:** Organized HTML structure and reusable CSS variables for easy theme management.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure.
* **CSS3:** Custom animations, Flexbox, and CSS Grid.
* **Fonts:** [Poppins](https://fonts.google.com/specimen/Poppins) via Google Fonts.
